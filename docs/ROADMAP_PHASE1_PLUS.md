## 1. 波次规划（依赖驱动，可并行轨道）

```
Wave A 智能核心          Wave B 数据科学主线         Wave C 数据库深化(研究)
model_client ──┐         citation注入 ── τ研究 ──┐   PG迁移 ─ pgvector ─ FTS
   │           │              │                │      │(与B并行)
   ▼           ▼              ▼                ▼      ▼
eval考场 ──> 抽取agent ──> 排序v0.2 <── 敏感性分析   语义检索/去重
   │           │              ▲                        │
   └─标注者信度─┘         行为遥测(燃料)                 │
                                                          ▼
Wave D agent编队：状态核验 ◄─ 连接器+文献目录    去重/关系agent(嵌入向量)
                调度器+增量同步+源腐烂报警
                                                          │
Wave E AI上手做：attempt API ◄─ attempt Schema(已有) ◄────┘
                "AI试试看"会话(计算实验/形式化检查/文献深挖)
```

### Wave A：智能核心（第 1–2 周）——让系统第一次有大脑
| 任务 | 说明 | 完成标准 |
|---|---|---|
| A1 model_client | LLM 适配层；prompt 注册表驱动（版本化 prompt 已在仓） | 任一 TASK 契约可程序化调用 |
| A2 **评估考场** | 金标准 30 卡第一次当考卷：抽取/规范化/评分三科对答案 | 输出质量报告（字段级 F1、分差分布） |
| A3 标注者信度 | 主人手标 10 卡 vs LLM 量表分 | ICC/κ 报告 → 决定 rubric 是否重构 |
| A4 抽取 agent 上线 | 原料(raw/) → 候选卡，规则版退休 | 考场达标（如字段 F1≥0.8）才放行 |

### Wave B：数据科学主线（第 2–4 周）——回应"现在不科学"
| 任务 | 说明 | 完成标准 |
|---|---|---|
| B1 引用特征注入 | OpenAlex cited_by → log 变换 → MSC 域内 z 分 | 30 卡全部有引用特征向量 |
| B2 **τ 研究** | 量表 I vs 引用 I 的 Kendall τ | 相关性报告（低相关=重构证据） |
| B3 敏感性分析 | 9 维权重扰动 × {几何,线性,min} 聚合 | Top-10 稳定性区间图 |
| B4 排序 v0.2 | 构念分离（重要性/AI友好/贴合）+ 成文权重 + 证据厚度加权 | ADR-015 + 消融报告 |
| B5 行为遥测 | 抽卡/点击/停留日志表 | LTR 燃料开始积累 |

### Wave C：数据库深化（第 3–5 周，研究重点，与 B 并行）
| 任务 | 说明 | 研究价值 |
|---|---|---|
| C1 PostgreSQL + Alembic 上生产栈 | docker-compose 已备（Docker 装机后） | 运维基础 |
| C2 **pgvector 语句嵌入** | 陈述向量化 → 语义去重候选对 + 相似卡检索 | 直接喂 TASK-301；对比专用向量库 |
| C3 全文检索 | PG FTS / zbMATH MSC 索引 / 数学公式检索难点 | 数学 IR 小课题 |
| C4 版本表治理 | card_versions 增长 → 分区/压缩策略 | 审计轨迹的工程化 |
| C5 工作负载基准 | SQLite vs PG 在我们查询模式下 | 可写小论文级实验 |

### Wave D：agent 编队（第 5–8 周）
| 任务 | 说明 |
|---|---|
| D1 **状态核验 agent（最高科学价值）**：定期复查每张卡状态，产出 status_review 信号 |
| D2 去重/关系 agent：嵌入向量找候选对，**合并永远人工**（ADR 红线） |
| D3 调度器 + 增量同步 + last_successful_sync 记账 |
| D4 源腐烂报警（OPG 污染就是第一案例研究） |

### Wave E：AI 上手做（第 8 周+）——"不建求解系统，但让 AI 真刀真枪试"
| 任务 | 说明 | 红线 |
|---|---|---|
| E1 attempt API + UI | attempt Schema（六族之一）从图纸变接口 | 尝试≠结论 |
| E2 "AI 试试看"会话 | 每张卡可发起：计算实验 / 形式化可表达性检查 / 文献深挖，产物全部进 attempt 记录 | 不自动翻转状态；无概率语义 |
| E3 attempted_methods 回填 | 卡上累积"试过什么" | 证据纪律照旧 |
