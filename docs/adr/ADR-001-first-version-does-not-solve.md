# ADR-001：第一版不直接求解

- 状态：Accepted（设计基线 v0.1 §25）
- 日期：2026-08-27（基线）/ 2026-08-28（Phase 0 落地注记）

## 背景

项目面对两类完全不同的需求：发现并推荐值得尝试的开放问题（信息问题），以及实际执行求解（研究执行问题）。任何试图同时做两者的第一版都会两头落空。

## 决策

第一版只建立问题池、评估与推荐排序，不运行完整求解流程，不做自动证明。

## 理由

项目的第一性问题是发现与配置研究机会，而不是再造一个通用数学求解 Agent。

## 后果

- 求解相关能力（Harness/Solver Backend）推到 Phase 5，且通过 `packages/solver_backends` 的可替换接口隔离（ADR-002）。
- Attempt Schema（schemas/attempt v1.0.0）已随 Phase 0 落盘，但只作为未来记录格式，不产生任何数据。
- 金标准集中包含的"已解决对照卡"（Erdős 偏差、开普勒、连续统假设）仅用于状态核验纪律，不构成求解实验。

## Phase 0 落地注记

本仓库 apps/* 与生产服务代码均为占位；唯一实现的是无副作用的领域包（packages/domain）、排序包（packages/ranking）与校验脚本，符合本 ADR。
