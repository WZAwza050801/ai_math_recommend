# ADR-003：使用关系数据库作为主数据源

- 状态：Accepted（设计基线 v0.1 §25）
- 日期：2026-08-27（基线）/ 2026-08-28（Phase 0 落地注记）

## 背景

问题卡、来源、证据、状态、审核与版本之间存在大量需要严格一致性的关系；同时去重召回希望用向量检索。

## 决策

以 PostgreSQL 关系数据库为主数据源；向量检索（pgvector）只作为辅助召回信号。

## 理由

实体、版本、来源、状态和审核关系需要严格一致性。向量检索只是辅助召回。

## 后果

- 去重召回的相似度分数只是信号，不是证据；任何合并与关系判定走 TASK-301 的人工门禁。
- Phase 0 以文件（data/gold_set/*.json）承载卡片，Schema 与关系结构设计已按未来关系模型建模（problem_id 外键式引用、evidence 内嵌）。
- docker-compose.yml 提供 PostgreSQL + pgvector 服务定义（Phase 1 启用）。
