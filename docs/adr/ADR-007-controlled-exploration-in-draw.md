# ADR-007：抽卡包含受控探索

- 状态：Accepted（设计基线 v0.1 §25）
- 日期：2026-08-27（基线）/ 2026-08-28（Phase 0 落地注记）

## 背景

完全按用户偏好与相关性的排序会造成领域封闭（用户永远只看到自己领域的高分卡），也丧失发现跨领域机会的系统价值。

## 决策

抽卡池按受控混合比例生成：默认 80% 高相关 / 15% 邻近领域探索 / 5% 远距离偶遇；用户可在稳健/平衡/冒险三模式间选择。

## 理由

完全相关性排序会造成领域封闭，也无法发现跨领域机会。

## 后果

- packages/ranking 的 PoolMix 实现三模式（steady 90/8/2、balanced 80/15/5、adventurous 65/25/10），比例和恒为 1（有测试）。
- 任何比例修改必须更新 ranking-weights 版本号并记 ADR。
- 抽卡不是纯随机抽样，也不得采用诱导沉迷的博彩式交互（§3.7）。
