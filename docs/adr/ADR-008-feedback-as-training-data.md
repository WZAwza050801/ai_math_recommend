# ADR-008：UX 反馈同时是未来训练数据

- 状态：Accepted（设计基线 v0.1 §25）
- 日期：2026-08-27（基线）/ 2026-08-28（Phase 0 落地注记）

## 背景

研究者在使用中产生的跳过原因、纠错与成对偏好是未来 Learning to Rank 与 AI 可解性预测最有价值的数据，但其语义各不相同。

## 决策

所有交互反馈以结构化事件持久保存（支持撤销与去重），并同时作为未来训练数据积累。

## 理由

低负担纠错、跳过原因和成对选择可以形成高价值标签，但不得把兴趣误当作重要性。

## 后果

- TASK-901 契约定义动作枚举与幂等/undo 语义；纠错类反馈必须生成审核任务，不得静默丢弃。
- 三类信号（兴趣标签/重要性异议/AI 友好性异议）在数据层严格分离，不得互写（§19.2）。
- 点击率永远不得改写重要性权重（§12 P9）。
